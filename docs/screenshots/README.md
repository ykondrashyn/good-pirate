# Preview screenshots

These images were captured from the published `v0.1.0-preview.1` WebGL build
running locally in Chromium on 2026-10-17. The runtime source commit is
`33d6de30430d53611cb735f11041e4c507923dec`.

- `harbor-tutorial.png`: the island pier and Set Sail tutorial.
- `steering-tutorial.png`: ships at sea during the drag-to-steer tutorial.
- `cannon-tutorial.png`: the early enemy-ship and cannon tutorial.

The PNG files are unchanged copies of game-viewport captures from the release
smoke checks. No browser chrome, personal tabs or device interface is included.
Tutorial overlays and interface elements are rendered by the game.

The images illustrate the preview, not full-content or long-session acceptance.
Recovered game artwork retains its original ownership. See
[provenance and dependencies](../publication/PROVENANCE.md).
